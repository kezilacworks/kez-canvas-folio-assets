Reserved Font Name
  "Mona" is a Reserved Font Name under the OFL. You may modify the font, but a
  modified version must be released under a different name. Using it unmodified,
  as this template does, is unrestricted.


REPLACING A FONT
  If you swap a font out, delete its file from fonts/, remove its @font-face
  block and any preload link (styles.css and index.html), and delete its entry
  here. Shipping a license notice for a font you no longer include is confusing;
  shipping a font without its notice is a licence violation.
